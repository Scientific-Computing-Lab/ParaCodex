void bpnn_hidden_error(delta_h,   
					   nh, 
					   delta_o, 
					   no, 
					   who, 
					   hidden, 
					   err)
float *delta_h, *delta_o, *hidden, **who, *err;
int nh, no;
{
  int j, k;
  float h, sum, errsum;

  errsum = 0.0;
  for (j = 1; j <= nh; j++) {
    h = hidden[j];
    sum = 0.0;
    for (k = 1; k <= no; k++) {
      sum += delta_o[k] * who[j][k];
    }
    delta_h[j] = h * (1.0 - h) * sum;
    errsum += ABS(delta_h[j]);
  }
  *err = errsum;
}

     7	- Use a single fused offload unit in `bpnn_train_kernel()`.
     8	- Flatten the pointer-to-pointer weight matrices into contiguous temporary buffers before the device launch.
     9	- Keep the activations, deltas, and scalar errors as direct 1D arrays.
    10	- Copy the updated flat weight buffers back into the original 2D host matrices after the device region.
    11	
    12	## Arrays Inventory
    13	
    14	### Direct 1D arrays
    15	- `input_units` - read on device, bias element updated on host before the launch.
    16	- `hidden_units` - written on device, copied back after the launch.
    17	- `output_units` - written on device, copied back after the launch.
    18	- `hidden_delta` - written on device, copied back after the launch.
    19	- `output_delta` - written on device, copied back after the launch.
    20	- `target` - read on device.

    22	### Flattened 2D arrays
    23	- `input_weights_flat` - device copy of `net->input_weights`.
    24	- `hidden_weights_flat` - device copy of `net->hidden_weights`.
    25	- `input_prev_weights_flat` - device copy of `net->input_prev_weights`.
    26	- `hidden_prev_weights_flat` - device copy of `net->hidden_prev_weights`.
    27	
    28	## Data Movement Strategy
    29	
    30	### H->D Transfers
    31	- Pack the four 2D matrices into flat host buffers.
    32	- Map the 1D activation and delta arrays to the device for the full fused compute region.
    33	- Map the packed weight buffers to the device for the full fused compute region.
    34	
    35	### D->H Transfers
    36	- Copy `hidden_units`, `output_units`, `hidden_delta`, `output_delta`, and the packed weight buffers back after the fused kernel.
    37	- Unpack the updated flat buffers into the original host 2D matrices.
    38	
    39	## Functions in Timed Region
    40	
    41	### Must run on device
    42	- `bpnn_train_kernel()` body
    43	
    44	### Kept on host
    45	- `bpnn_layerforward()`
    46	- `bpnn_output_error()`
    47	- `bpnn_hidden_error()`
    48	- `bpnn_adjust_weights()`
    49	
    50	## Loop Structure
    51	- Forward pass over hidden layer: parallel over hidden units.
    52	- Forward pass over output layer: parallel over output units.
    53	- Output error: parallel over output units.
    54	- Hidden error: parallel over hidden units.
    55	- Output weight update: parallel over output units.
    56	- Hidden weight update: parallel over hidden units.
    57	
    58	## Correctness and Scale
    59	- Default correctness size: `262144` input elements.
    60	- Larger profiling size: `>= 262144` input elements, with `1,000,000` preferred if memory allows.
    61	
    62	## Notes
    63	- This benchmark uses pointer-to-pointer matrices, which are awkward for direct OpenMP deep copy.
    64	- Flattening avoids repeated deep-copy bookkeeping and keeps the GPU region structurally simple for step 1.
